核心机制

  • 意图路由：CHAT / DISCUSS / WORK / CONCLUDE
  • 判定讨论 → 追溯式自动建题
  • SpeakerScheduler 评分调度轮流发言
  • [[PASS]] / [[CONCLUDE]] 协作收束
  • STAR 结论 → 异步提取 Q&A 知识卡片

线程模型

  • 每群一个单线程虚拟线程执行器（group-{id}-）
  • 群内串行免锁，跨群并行
  • 画像提炼 / 卡片生成独立虚拟线程
  • ConclusionWatchdog（60s）卡死主题回滚
  • CardReconciler（10min）对账补卡

降级哲学

  • Moderator 失败 → 回退 SpeakerScheduler
  • Agent 失败 → 接力下一候选
  • 流式异常 → ABORT，不卡死群执行器
  • RAG / 画像失败 → 静默降级不阻塞主流程
  • Nacos 不可用 → 降级 classpath 提示词
